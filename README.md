## Run Locally

This is a static website and does not require a package installation or build step.

1. Clone the repository:

   ```bash
   git clone https://github.com/ZayanHasanTaj/zayan-hasan-portfolio.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

## Deploy to Vercel

1. Push the project to GitHub.
2. In Vercel, choose **Add New Project** and import the GitHub repository.
3. Select **Other** as the framework preset.
4. Leave the build command empty and set the output directory to `.` (the repository root).
5. Deploy the project.

Vercel will redeploy the site when you push changes to the connected GitHub repository.
